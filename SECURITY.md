# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

FitMeister takes security and user privacy seriously. If you discover a security vulnerability or race-condition vulnerability within the booking system or authorization flow:

1. **Do not create a public GitHub issue.**
2. Email your findings confidentially to: [nabilpwqz@gmail.com](mailto:nabilpwqz@gmail.com) with the subject `[SECURITY] FitMeister Vulnerability Report`.
3. Include:
   - Detailed steps or curl script to reproduce the vulnerability
   - Potential impact
   - Proposed remediation if available

We will acknowledge receipt within 24 hours and provide a timeline for patch deployment.
